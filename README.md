# Kanban Board

A simple, interactive Kanban board built with vanilla JavaScript for task management practice.

## Features

- **Three Columns**: Organize tasks across "To Do", "In Progress", and "Done" columns
- **Add Tasks**: Create new tasks with a title and description through a modal form
- **Drag & Drop**: Move tasks between columns with intuitive drag and drop functionality
- **Delete Tasks**: Remove completed or unnecessary tasks with a single click
- **Persistent Storage**: Tasks are automatically saved to local storage and persist across browser sessions
- **Task Counter**: Each column displays the current number of tasks

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Flexbox)
- Vanilla JavaScript (DOM manipulation, Drag & Drop API, Local Storage)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/tanvihedau/Kanban.git
   ```

2. Open `index.html` in your web browser

No build tools or dependencies required!

## How to Use

1. Click the **"Add new Task"** button in the navigation bar
2. Enter a task title and description in the modal form
3. Click **"Add Task"** to create the task in the "To Do" column
4. Drag tasks between columns to update their status
5. Click the **"Delete"** button on any task to remove it
